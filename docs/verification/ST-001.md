## Integration handoff

Status: not integrated. The existing ruleset requires an eligible owner-team review and approval of the latest push.
This setup does not remove that requirement or use an administrative merge bypass.
A required reviewer must review PR #14 through GitHub.

After approval, inspect the current checks and merge through the normal protected path:

```sh
gh pr view 14 --repo Team-Teddy-Development/story-time --json headRefOid,reviewDecision,statusCheckRollup
head=$(gh pr view 14 --repo Team-Teddy-Development/story-time --json headRefOid --jq .headRefOid)
gh pr merge 14 --repo Team-Teddy-Development/story-time --squash --match-head-commit "$head"
```

After merge, use a run-owned checkout of the latest main to accept ST-001 with the merge evidence and mirror its final status to GitHub.
Until integration, new branches from main do not inherit the workflows and their PRs cannot satisfy the new required contexts without the bootstrap changes.

## Recovery

The new ruleset is additive. To undo this rollout, remove only ruleset 27056058 and revert the configuration PR through a reviewed PR.
Do not change owner-review ruleset 26702417.
The checked-in `.github/story-mandate-ruleset.json` records the new rule's intended state.
Local pre-change snapshots were retained at `/tmp/story-time-rulesets-before-20261111.json` and `/tmp/story-time-owner-ruleset-before-20261111.json`.
