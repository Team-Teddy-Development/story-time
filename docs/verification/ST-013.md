## Reproduction and proof

The old binary used caller-relative filesystem reads, `rustc` source paths, and Node reference CLI paths. Running it from the stale shared anchor selected missing or outdated files. Changing only the calling directory corrected the immediate operation but did not remove this recurring source defect.

The new regression invokes the real contract binary from a disposable unrelated Git directory, captures its output, requires successful execution, and checks that the five named contract tests actually ran successfully. The test-only parent failed with the asserted message `contract suite selected the caller directory instead of its source checkout:` and exit 101. The source-only fix passes that regression without changing the original assertions.

Run from the repair checkout:

```sh
rustc --edition=2021 -Dwarnings --test test/story-policy-contract.rs -o /tmp/ST-013-contract
/tmp/ST-013-contract
(cd /tmp && /tmp/ST-013-contract)
(cd /home/ejernigan/source/team-teddy/story-time && /tmp/ST-013-contract)
```

Each invocation passed 11 tests with zero failures. The suite itself includes the unrelated-directory child execution. The complete retained reference suite passed 408 tests with zero failures or skips. The Rust story-policy suite passed 12 tests with zero failures.

Compile in the correct run-owned checkout. The binary intentionally remains bound to that checkout; rebuild it after relocating or removing its source. Relative source compilation uses compile-time `PWD`; absolute source compilation uses `file!()` directly. No runtime root override can redirect the test to another repository.
