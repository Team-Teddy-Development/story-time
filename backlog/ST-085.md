## Story
As a maintainer, I want native adoption to read every legacy story Node reads, so that adoption never refuses a story the rest of the CLI accepts.

## Acceptance Criteria
- [x] Given a legacy story with a colon-space value, a duplicate key, and prose before the first section, when native story adopt preview runs, then it does not refuse the story, verified by a native/story-push contract test

## Notes
Source: ST-081 (PR #161). Adoption still reads legacy stories with the strict `story::parse_legacy`.
