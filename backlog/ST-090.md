## Story
As a maintainer, I want test runs to delete their temporary folders, so that /tmp does not fill up across runs.

## Acceptance Criteria
- [x] Given a clean /tmp, when npm test runs to completion, then no story-judge-* folder it created remains, verified by a native/story-push test that runs the suite in a private TMPDIR and lists it afterwards

## Notes
Source: ST-056 (PR #173) report. /tmp held 318 `story-judge-*` folders from earlier Node test runs.

## Evidence
- Finding: the npm suite already leaves no `story-judge-*` folder. ST-070's `native/story-push/tests/npm_temp_cleanup.rs` runs `npm test` in a private TMPDIR and asserts it is empty; it passes. The 318 old folders in /tmp predate ST-070 (newest 01:23). None were deleted.
- Live leak found: `test/story-policy-contract.rs` compiled a 4.8 MB checker to `$TMPDIR/story-policy-contract-<pid>` per process and never removed it (218 in /tmp).
- Red 565d8c1: `tests/policy_contract_temp_cleanup.rs` failed with `the policy contract left 2 entries in TMPDIR`.
- Green aaec41a: the checker is built at `<contract exe>-checker` under a per-pid staging name, then renamed into place.
- Checks: `cargo fmt --check` ok; `cargo clippy --locked --all-targets -- -D warnings` ok; `cargo test --locked` 300 passed, 0 failed; `npm test` 461/461; `scripts/story-policy.rs` 12 passed; `test/story-policy-contract.rs` 11 passed.
