## Story
As a story-time maintainer, I want working setup help and validated GitHub examples, so that I can configure a repository without guessing argument or settings formats.

## Acceptance Criteria
- [ ] Given an unconfigured directory with no Node on PATH, when story init --help or story init -h runs, then it exits zero, explains --from and --force, and writes no files.
- [ ] Given the GitHub JSON example in story-setup, when story init consumes it, then it succeeds and story config reports github.repo as acme/shop.
- [ ] Given a GitHub example with a bare repo name, when story init consumes it, then it rejects the configuration before writing files.
- [ ] Given the installed story CLI and story-setup skill, when the regression tests run, then the help and example contracts pass for the installed artifacts.

## User journey
A maintainer asks for setup help before a config exists, copies the GitHub example into an answers file, initializes the repository, and reads back the effective config. A malformed repository coordinate is rejected before any settings are written.

## Definition of Done
Both original fingerprints have actual source corrections and Rust regression evidence. The installed CLI and skill pass the same contract tests. Required regression checks and protected PR integration pass, or a concrete delivery blocker is recorded without a completion claim.
