## Story
As a story-time maintainer, I want working setup help and validated GitHub examples, so that I can configure a repository without guessing argument or settings formats.

## Acceptance Criteria
- [x] Given an unconfigured directory with no Node on PATH, when story init --help or story init -h runs, then it exits zero, explains --from and --force, and writes no files.
- [x] Given the GitHub JSON example in story-setup, when story init consumes it, then it succeeds and story config reports github.repo as acme/shop.

- [x] Given the installed story CLI and story-setup skill, when the regression tests run, then the help and example contracts pass for the installed artifacts.
