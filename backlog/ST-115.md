## Story
As a repository owner who exposes story lint to MCP clients, I want lint to refuse state_machine paths outside the repository, so that no client can learn which files exist elsewhere on the machine.

## Acceptance Criteria
- [x] Given a story whose state_machine path resolves outside the repository root (../ or absolute or a symlink), when story lint or the MCP story_lint tool runs, then the finding reports the path as outside the repository without checking whether that path exists, verified by a native/story-push test that compares the output for an existing and a missing outside path

## Notes
Source: ST-111 (PR #249) agent report and Jev review (lint_probe, 0.77). The state_machine.exists rule checks root.join(path).exists(), so a ../ path reveals whether a file outside the root exists. Through MCP story_lint this reaches clients; with ST-112 write tools a client could set the field. ST-112 depends on this story.

## Evidence
- Criterion 1: `native/story-push/tests/lint_contract.rs` `a_machine_outside_the_root_reads_the_same_whether_it_exists` lints a story whose `state_machine` is `../`, absolute, a symlinked directory, or a symlinked file, each with an existing and a missing outside target. It runs Node and native `lint --json` and asserts equal stdout, stderr, exit code and file snapshot. Each pair gives the identical single finding "is outside the repository". `tests/mcp_protocol.rs` `story_lint_reads_an_outside_machine_the_same_whether_it_exists` asserts the same for the MCP `story_lint` tool.
- Red (7bd2120): an existing outside path gave no finding, and a missing outside path gave "does not exist", in both CLI and MCP.
- Green (8bb2364): `lint.rs` `place()` resolves the path lexically against the canonical root and returns `Outside` with no file-system call when the path leaves the root. Inside the root it walks the path with `symlink_metadata` and `read_link` and never follows a link. Node `inRepo` and `invest.mjs` changed the same way for parity. `story set` and MCP `story_lint` inherit the fix through `lint::lint_story`.
- Checks on the rebased branch: fmt ok; clippy clean; cargo 71 binaries, 359 passed, 0 failed; npm pass 457 fail 0; story-policy 12 passed; contract 11 passed.
- Real data: native (PATH=/nonexistent) and Node `story lint` and `story lint --json` on this backlog (115 stories) gave byte-identical output.
