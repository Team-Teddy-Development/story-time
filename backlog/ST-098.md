## Story
As a maintainer, I want push --all on an empty or missing backlog to behave the same in Node and native, so that the two runtimes never disagree.

## Acceptance Criteria
- [x] Given an empty backlog directory, when Node and native story push --all --dry-run run, then their stdout, stderr, and exit code are equal, verified by a native/story-push contract test

## Notes
Source: ST-091 follow-up report. Native exits 0 with an empty plan for `push --all` on an empty or missing backlog, the documented fix es_9c55035c0ff8 (docs/empty-push-es-9c55035c0ff8.md, tests/empty-push.rs); Node exits 2 with usage. Read that record first: the likely fix is Node matching the documented native behavior, not the reverse.

## Evidence
- Decision: Node matches native. `docs/empty-push-es-9c55035c0ff8.md` (Root cause) says "An empty backlog is a valid result for `--all --dry-run`. Missing explicit targets must still produce a usage error.", and its first gate requires `{"ok":true,"plan":[]}` with exit 0; `tests/empty-push.rs` encodes that contract.
- Red 2a73903: `push_all_on_an_empty_or_missing_backlog_agrees_with_node` failed with native `("Action  ID  Remote\n", "", Some(0))` against Node `("", "Usage: story push <id...> | --all [--dry-run]\n", Some(2))`; the Node test failed with `actual: 2, expected: 0`.
- Green 39b3b99: the Node push handler raises the usage error only when `!f.all && !targets.length`; an empty target list returns `{ok:true,plan:[]}` (dry run) or `{ok:true,pushed:[],skipped:[]}` without building the gateway. The ST-091 refusals are unchanged.
- The contract test covers an empty and a missing backlog for `--all --dry-run`, `--json`, `--all`, `--all --json`, `--dry-run`, and `--json`, compares stdout, stderr, and exit code with Node, pins the expected output, and checks nothing is written. `cli-push.test.mjs` adds the Node case with no credential. `tests/empty-push.rs` passes 3/3 against Node. The doc's first gate is marked MET.
- Real backlog: `push --all --dry-run` with and without `--json`, Node and native byte-identical (99 and 495 lines, exit 0).
- Limit: a non-empty `push --all` where every story is skipped may still need a credential in Node but not native (untested).
