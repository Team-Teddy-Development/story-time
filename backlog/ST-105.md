## Story
As a maintainer setting up a machine or a repository, I want the skill installer to run in Rust, so that installing story-time needs no Node, as Constitution Article VIII requires.

## Acceptance Criteria
- [ ] Given a temporary HOME and a project directory, when the Rust installer runs with each of --agent codex, claude and all, --scope project --project DIR, --codex-home DIR, --dry-run, --force and --uninstall, then it writes, refuses or removes the same files with the same exit codes as node scripts/install.mjs, verified by a native/story-push contract test
- [ ] Given README.md, when a user reads the Installer section, then it tells them to run the Rust installer and no longer names node scripts/install.mjs, verified by a native/story-push test that reads the README

## Notes
Source: ST-104 (PR #220) agent report, checked by the coordinator. scripts/install.mjs (134 lines, Node) is the skill installer that README.md lines 103-105 and 147 tell users to run; test/install.test.mjs tests it. Flags: --agent, --scope project --project DIR, --codex-home DIR, --dry-run, --force, --uninstall. The Rust story-install (ST-040) copies skills at user scope only. Article VIII requires Rust for active executables.
