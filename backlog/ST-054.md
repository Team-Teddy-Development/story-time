## Story
As a story-time maintainer, I want story stats to run in the native Rust binary, so that the backlog health summary works without Node and the retained Node CLI shrinks.

## Acceptance Criteria
- [x] Given a fixture backlog and no Node or STORY_TIME_LEGACY_CLI, when the native binary runs story stats with the arguments its Node version accepts, then its stdout, exit code, and file changes match the Node CLI on the same fixture, verified by a native/story-push contract test

## Out of Scope
Changing the command's behavior or output. Converting other commands.

## Notes
Source: ST-036 (Rust conversion plan, epic EP-001, map backlog/EP-001.map.md). Slice: Rest. Constitution Article VIII requires Rust for replacement implementations. Today native/story-push/src/main.rs runs init, push, adopt, and plan natively and passes every other command to skills/story-time/scripts/story.mjs.

## Evidence
- Red 010d4dd: all 5 tests in native/story-push/tests/stats_contract.rs failed; native `stats` fell through to the legacy dispatcher (empty stdout).
- Green fdaed53: native/story-push/src/stats.rs ports backlogStats and its text and JSON output, reusing list::stories, list::backlog_dir, config::load and parse, Flags::parse, and lenient_story. It ports JS `Number(string)` for --stale-days, `Date.parse` for the ECMAScript ISO format, and JS truthiness. `stats` is one NATIVE_COMMANDS entry. legacy_dispatch.rs now uses `not-a-native-command` as its sample legacy command.
- stats_contract compares stdout, exit code, and a byte and mode snapshot against Node: statuses as numbers, missing, or arrays; fractional sizes (0.1+0.2); many `updated` forms; 20 --stale-days values; usage errors; empty, missing, and broken backlogs; missing and non-string ids. 5 passed.
- Real data: native (PATH=/nonexistent) against Node on this backlog for no flags, --json, --stale-days 0, --stale-days 1 --json: compared=4 differing=0 after rebase (7/7 before rebase).
- Checks after rebase on main f8a3232: cargo fmt --check clean; clippy -D warnings clean; cargo test --locked 232 passed, 0 failed (46 binaries); npm test 456/456; story-policy.rs 12 passed; story-policy-contract.rs 11 passed.
- Limits: dates only V8's legacy parser accepts (such as `2026/11/14`) read as NaN natively; every real `updated` value is YYYY-MM-DD.
