## Story
As an agent, I want list, lint, stats, plan, and adopt to use one rule for which backlog files are stories, so that a stray file never passes one command and fails another.

## Acceptance Criteria
- [ ] Given a backlog directory with a story, an epic map, and a stray notes.md, when list, lint, stats, plan --snapshot, and adopt preview run, then all of them treat notes.md the same way under one documented rule, verified by a native/story-push test

## Notes
Source: ST-097 (PR #204). Today `list`, `lint`, and `stats` read only `<PREFIX>-<digits>.md` names and skip a stray notes.md, while `plan` and `adopt` read every non-map `.md` as a story and stop with an error. Owner decision needed before readiness: which rule should all commands share (skip non-ID names, or refuse them).
