## Story
As a maintainer, I want one function to resolve the backlog directory, so that --dir, STORY_TIME_DIR, and backlogDir behave the same in every native command.

## Acceptance Criteria
- [x] Given each of --dir, STORY_TIME_DIR, backlogDir, and no setting, when native show, export, list, and lint run, then each resolves the same directory, verified by a native/story-push contract test, and show.rs calls list::backlog_dir

## Notes
Source: ST-049 (PR #162) agent report. `show::read` repeats the --dir / STORY_TIME_DIR / backlogDir logic that `list::backlog_dir` holds, with `.unwrap()` where list falls back to `backlog`.

## Evidence
- Red 1fa8a01: `tests/backlog_dir_contract.rs` failed for `push --all --dry-run --json` with `STORY_TIME_DIR=""`, where native read backlogDir and Node read the project root.
- Green 4806256: `list::backlog_dir` takes `Option<&str>`; show (and so export), metrics, push/issues `context()`, and every other caller use it; each copy is deleted. `grep STORY_TIME_DIR native/story-push/src` finds only list.rs.
- The contract test runs show, export, list, lint, stats, rank, and push dry-run under no setting, backlogDir, STORY_TIME_DIR, an empty STORY_TIME_DIR, --dir with STORY_TIME_DIR, and a dotted --dir, comparing Node and native.
- Real backlog: 552 runs compared under 3 settings, 3 differing, all `metrics` (Node has no handler; native output identical across settings).
