## Story
As a user following README.md, I want the installer instructions to name the Rust installer, so that I do not need Node to install story-time.

## Acceptance Criteria
- [x] Given README.md, when a user reads the Installer and Claude Code sections, then they tell the user to run the Rust installer and no longer name node scripts/install.mjs, verified by a native/story-push test that reads the README

## Notes
Run command: story-install puts only story on PATH; the skill installer runs from a checkout with cargo run --locked --manifest-path native/story-push/Cargo.toml --bin story-install-skills -- --agent all (see the PR #228 comment).
Source: split from ST-105 (#221, PR #226). scripts/install.mjs (134 lines, Node) is the skill installer; README.md lines 103-105 and 147 name it, and test/install.test.mjs tests it. The Rust story-install (ST-040) already copies skills at user scope.
