## Story
As a Sentinel maintainer, I want the native Gitea gateway to accept private LAN HTTP endpoints so that SNT stories can use the configured local tracker.

## Acceptance Criteria
- [x] Given an RFC1918 IPv4 literal or an IPv6 unique-local literal, when the native gateway validates an HTTP base URL, then it accepts the endpoint and a story dry run renders a plan without a token or writes.
- [x] Given public, link-local, unspecified, multicast, or hostname HTTP URLs, when the gateway validates them, then it rejects them while preserving HTTPS and loopback behavior.

## Out of Scope
Public or hostname HTTP access, DNS resolution, transport retries, credential changes, and conversion of legacy Story Time commands.
