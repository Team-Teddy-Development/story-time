## Story
As a maintainer, I want the Node skill installer and its Node test removed once the Rust installer replaces it, so that no active installer path needs Node, as Constitution Article VIII requires.

## Acceptance Criteria
- [x] Given install_skills_contract.rs, when scripts/install.mjs is removed, then every case it covered still runs and compares the Rust installer's stdout, stderr, exit code and tree against fixed expected values recorded from the Node installer before removal, verified by cargo test
- [x] Given the repository after ST-108, when a maintainer looks for the skill installer, then scripts/install.mjs and test/install.test.mjs are absent, no tracked file outside backlog/, docs/verification/, docs/planning/verification.md and docs/designs/gap-sweep-review/ contains "node scripts/install.mjs", and npm test passes, verified by a native/story-push test that checks the files are absent and greps the tracked files

## Notes
Source: ST-107 (PR #229) agent report and the ST-105 split (PR #226 comment: retire install.mjs once ST-106 and ST-107 pass). scripts/install.mjs reads inherited object keys (--agent constructor gives the wrong error; --scope toString plans writes into [object Undefined]/) and with HOME set but empty plans relative folders in the cwd; the Rust installer has neither defect. install_skills_contract.rs runs node scripts/install.mjs as its oracle, so its cases must be frozen to fixed expectations first, as ST-096 did for the Node story fallback.

In the same commit, `install_skills_contract.rs` ran both Node and the Rust installer against the new fixed expectations. All 14 tests passed for both, which proves the recorded values are Node's.

It deletes `scripts/install.mjs` and `test/install.test.mjs`. `adoption_contract.rs`, `adoption_preview_install.rs` and `planning_install.rs` now run `story-install-skills`. Each case compares stdout, stderr, exit code and the full tree with modes and bytes. The two usage-text differences stay explicit. That fixture is not an instruction to run the Node installer.
- AC2: `node_installer_retired.rs` checks that both files are absent. It greps `git ls-files` for "node scripts/install.mjs" outside backlog/, docs/verification/, docs/planning/verification.md and docs/designs/gap-sweep-review/. `npm test` passes, 457/457 after removing the 10 install tests.
