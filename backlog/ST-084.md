## Story
As a maintainer, I want native settings errors to echo numbers as Node does, so that native and Node give the same message for the same settings file.

## Acceptance Criteria
- [ ] Given settings.json whose tracker is 9007199254740993 or 1e400, when native story config runs, then its stderr and exit code equal the Node CLI output, verified by a case in native/story-push/tests/config_contract.rs

## Notes
Source: ST-082 (PR #159). serde_json stores settings integers as u64/i64 and prints them exactly where JavaScript rounds above 2^53, and it rejects `1e400` where JSON.parse returns Infinity.
