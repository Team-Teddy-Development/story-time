## Story
As a maintainer working in a story-time checkout, I want native story to use the checkout's own Node CLI, so that commands run the code under test instead of an installed release.

## Acceptance Criteria
- [x] Given a story-time checkout with skills/story-time/scripts/story.mjs and STORY_TIME_LEGACY_CLI unset, when native story runs a non-native command from inside that checkout, then it dispatches to that checkout's story.mjs, verified by a native/story-push integration test
- [x] Given STORY_TIME_LEGACY_CLI is set, when native story runs a non-native command anywhere, then it dispatches to that path as before
- [x] Given a directory that is not a story-time checkout, when native story runs a non-native command, then it uses runtime.json legacyCli as before

## Out of Scope
Changing runtime.json or the installer. Native init, push, adopt, and plan, which do not dispatch.
