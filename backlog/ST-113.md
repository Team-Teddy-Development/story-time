## Story
As a coding agent operator, I want story_create to allocate a new id without replacing or duplicating a story, so that parallel agents can file work safely.

## Acceptance Criteria
- [ ] Given a new title, when story_create runs, then it returns a new id and the file equals what story new produces apart from the date, verified by a native/story-push protocol test
- [ ] Given an existing title, when story_create runs without allow_duplicate_title, then the result is duplicate_title and nothing is written, verified by a native/story-push protocol test
- [ ] Given a racing creator that takes the same id, when story_create saves, then no story is replaced and a second collision returns id_taken, verified by a native/story-push protocol test
- [ ] Given a real MCP client, when it creates a story, then the story appears in story list, recorded in the story Evidence
