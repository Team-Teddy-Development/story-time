## Story
As a story refiner using the hosted MCP, I want story_update to replace named sections, so that I can write acceptance criteria, notes and out-of-scope without pushing files through git.

Evidence (2026-11-26): native/story-push/src/set.rs:29 lists `sections` as IMMUTABLE, enforced in mcp.rs ~1398. Refiners pushed story files with git instead, which caused story-ids collisions. Scope: replace `Acceptance Criteria`, `Notes`, `Out of Scope`, `To plan`, `Story`, guarded by expected_sha256, with the CLI's sanitising and lint, appending a changelog line that names the changed sections. `Changelog` itself must never be writable.

## Acceptance Criteria
- [ ] Given a story and its current sha256, when story_update replaces the Acceptance Criteria and Notes sections, then story_show returns the new text and the changelog names both sections; and given a stale sha256 or a Changelog section, then the write is refused and the file is unchanged.
