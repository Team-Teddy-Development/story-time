## Story
As a team lead, I want every write that sets or changes size to log a `set size=N` changelog line, so that velocity counts the points of a story sized at creation.

Evidence (2026-11-26): ST-194 velocity reads points from `set size=` events (native/story-push/src/sprint.rs:223). `story set size=` already logs it (set.rs `apply`). `story new` and MCP story_create with a size write the frontmatter without the changelog line, so such a story counts as unknown points. Check story_update too.

## Acceptance Criteria
- [ ] Given a story created with size 3 and then moved to done inside a sprint, when story metrics or story sprint show runs, then the story counts 3 completed points rather than unknown.
