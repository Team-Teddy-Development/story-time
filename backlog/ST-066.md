## Story
As a project sponsor, I want a project-discovery skill, so that I can start a project from stated goals, users, and success measures before any backlog work.

## Acceptance Criteria
- [x] Given a user brief and existing project context, when the project-discovery skill runs, then it writes a project brief that separates validated from assumed facts, lists open decisions with owners, and traces every proposed epic to an outcome or marks it unresolved, and it does not estimate or schedule stories, verified by cargo test --test project_discovery_skill on skills/project-discovery/SKILL.md

## Out of Scope
Other lifecycle skills. Changing refinement, sprint-planning, or story-accept. Value scores and dates.
