## Story
As a story-time maintainer, I want story show to run in the native Rust binary, so that printing one story works without Node and the retained Node CLI shrinks.

## Acceptance Criteria
- [x] Given a fixture backlog and no Node or STORY_TIME_LEGACY_CLI, when the native binary runs story show with the arguments its Node version accepts, then its stdout, exit code, and file changes match the Node CLI on the same fixture, verified by a native/story-push contract test

## Out of Scope
Changing the command's behavior or output. Converting other commands.

## Notes
Source: ST-036 (Rust conversion plan, epic EP-001, map backlog/EP-001.map.md). Slice: Read. Constitution Article VIII requires Rust for replacement implementations. Today native/story-push/src/main.rs runs init, push, adopt, and plan natively and passes every other command to skills/story-time/scripts/story.mjs.

## Evidence
- Red f0f9b3f: 3 of 4 tests in native/story-push/tests/show_contract.rs failed; native `show` fell through to the legacy dispatcher (empty stdout, "Commands other than ... require STORY_TIME_LEGACY_CLI").
- Green 8cd0139: new native/story-push/src/show.rs ports Node's lenient parseStory, serializeStory, and JSON.stringify(..., 2), reusing config::load, Flags::parse, config::parse, and valid_id. Each case compares stdout, exit code, and a byte snapshot of the fixture tree: rich story in LF, CRLF, and lone CR; no sections; PAY-7 prefix; extra arguments; seven failure cases (exit 1); usage errors (exit 2); backlogDir, STORY_TIME_DIR (including empty), --dir, --config, STORY_TIME_CONFIG precedence; invalid config. 4 passed.
- Real data: native and Node `show` on all 71 stories in this backlog, plain and --json: compared=142 differing=0.
- Checks after rebase on main a3f69e6: cargo fmt --check clean; clippy -D warnings clean; cargo test --locked 154 passed, 0 failed (32 binaries); npm test 441/441; story-policy.rs 12 passed; story-policy-contract.rs 11 passed.
- Limits: stderr wording differs for bad JSON quoting, read errors, and invalid config JSON (stdout and exit code match). A lone surrogate escape that JSON.parse accepts makes native exit 1. A non-UTF-8 STORY_TIME_DIR is treated as unset.
