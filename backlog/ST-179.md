## Story
When an agent hits a blocker mid-story, it stops without freeing WIP or creating follow-on work. Add Story Time MCP tools so a blocked story is labeled, WIP is released, and a groomer pass can create N dependees that unblock the parent.

Ship per /cursor/stores/self/docs/unblocker-story-tool.md with Eric's approval of the proposed defaults: label-only `blocked` (no status:blocked in v1), label name `blocked`, parent depends_on → unblock children with relates_to parent, auto-clear when deps done plus explicit clear, recursive depth cap 2.

## Acceptance Criteria
- [ ] story_mark_blocked adds labels including blocked, notes reason, and with release_wip moves in-progress to ready
- [ ] story_propose_unblocks creates N children, wires parent depends_on and child relates_to, refuses cycles, respects max_children default 5
- [ ] story_clear_blocked removes blocked label; clear is refused while required unblock deps remain open; auto-clear when those deps are done
- [ ] story_list can filter by the blocked label; rank/assignment/poteto skip labeled-blocked parents
- [ ] Tests and real CLI/MCP behavior cover mark, propose, clear, cycle refuse, and WIP release
- [ ] PR opens, CI passes, and Stories declaration links the story id
