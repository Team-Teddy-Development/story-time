## Story
As a story-time maintainer, I want story push to report the tracker CLI's result when that CLI exits without reading stdin, so that push does not crash with an unhandled EPIPE.

## Acceptance Criteria
- [x] Given a tracker CLI that closes stdin and exits 0 before the input is written, when processExec runs it, then processExec resolves with that CLI's stdout and no unhandled EPIPE, verified by a Rust test that drives processExec
- [x] Given a tracker CLI that closes stdin and exits non-zero, when processExec runs it, then processExec rejects with that CLI's error

## Out of Scope
The test helper (fixed by ST-033). Retrying the tracker call.

## Notes
Source: found during ST-040 verification on 2026-11-13. One `npm test` run failed `push creates the GitHub issue and links it in the story file` (cli-push.test.mjs:51): the story CLI child crashed with an unhandled `write EPIPE` at skills/story-time/scripts/src/adapters/process-exec.mjs:21, where `child.stdin.end(input ?? '')` has no error listener. The fake `gh` can exit without reading stdin. This is likely the original cause behind #11; ST-033 fixed only the same pattern in the test helper. Affected command: story push (GitHub and ADO adapters).

## Test Plan
Red: a Rust test runs a Node driver that calls processExec on a child that closes fd 0 and exits 0 or 2, writing 1 MiB of input; it fails with an unhandled EPIPE. Green: an EPIPE-only stdin error listener in processExec. Verify with cargo test --locked in native/story-push and npm test.

## Evidence
- Red 9dbe937: native/story-push/tests/process_exec_stdin.rs drives processExec against a tracker that closes fd 0 and exits 0 or 2 while 1 MiB of input is written; both tests failed with an unhandled EPIPE.
- Green 9802938: processExec ignores EPIPE on stdin and rejects any other stdin error. Exit 0 resolves with the tracker's stdout; exit 2 rejects with its stderr. Both tests passed three runs in a row.
- cargo test --locked 88 passed 0 failed; npm test 426/426 three runs in a row; story-policy.rs 12/12; story-policy-contract.rs 11/11; fmt and clippy clean.
