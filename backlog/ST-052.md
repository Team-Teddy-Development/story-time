## Story
As a story-time maintainer, I want story new to run in the native Rust binary, so that creating a story works without Node and the retained Node CLI shrinks.

## Acceptance Criteria
- [ ] Given a fixture backlog and no Node or STORY_TIME_LEGACY_CLI, when the native binary runs story new with the arguments its Node version accepts, then its stdout, exit code, and file changes match the Node CLI on the same fixture, verified by a native/story-push contract test

## Out of Scope
Changing the command's behavior or output. Converting other commands.
