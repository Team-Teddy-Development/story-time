## Story
As a story-time maintainer, I want story lint to run in the native Rust binary, so that the Definition of Ready check works without Node and the retained Node CLI shrinks.

## Acceptance Criteria
- [x] Given a fixture backlog and no Node or STORY_TIME_LEGACY_CLI, when the native binary runs story lint with the arguments its Node version accepts, then its stdout, exit code, and file changes match the Node CLI on the same fixture, verified by a native/story-push contract test

## Out of Scope
Changing the command's behavior or output. Converting other commands.

## Notes
Source: ST-036 (Rust conversion plan, epic EP-001, map backlog/EP-001.map.md). Slice: Read. Constitution Article VIII requires Rust for replacement implementations. Today native/story-push/src/main.rs runs init, push, adopt, and plan natively and passes every other command to skills/story-time/scripts/story.mjs.

## Evidence
- Red cce7534: lint_contract failed all 6 tests (5 at the stdout comparison, 1 at stderr); native `lint` fell through to the legacy dispatcher.
- Green 5941563: native/story-push/src/lint.rs ports the Node lint rules as a rule table (`lint_story`, `ready`, shared STATEMENT, GHERKIN, and VAGUE patterns, `acceptance_criteria`) so readiness checks can reuse the core. `lint` is one NATIVE_COMMANDS entry returning exit 1 with its output when a story has errors. show.rs gains `require_all` for id validation and lookup through `list::get`. Adds the regex-lite dependency.
- lint_contract compares stdout, stderr, exit code, and a byte and mode snapshot against Node with no Node on PATH, over every rule, per-id runs, --json, and error cases: 6 passed.
- Real data: native (PATH=/nonexistent) against Node on this backlog: no args, --json, --dir, --config, a missing id, a bad id, an empty id, all 82 ids with --json, and each id alone and with --json: compared=173 differing=0. Neither run wrote files.
