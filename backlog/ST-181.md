## Story
As a developer new to Story Time, I want one onboarding path in `README.md`, so that I can install Story Time and create my first story without sorting through advanced setup options.

Out of scope: CLI or installer changes, tracker synchronization changes, and rewriting advanced documentation.

Notes: On the default branch, the README lists commands and agent installations before setup. Its `story new` example is in the later backlog reference. Keep the README quickstart self-contained and link to detailed setup paths where needed.

## Acceptance Criteria
- [ ] Given a first-time reader opens `README.md`, when they read the quickstart before the advanced sections, then they can identify the prerequisites, which installation steps are required, and what success looks like.
- [ ] Given a fresh test repository and the prerequisites listed in the README, when a reader follows only the quickstart, then `story list` displays the draft story they just created without requiring tracker credentials.
- [ ] Given the reader needs agent-specific installation, tracker synchronization, or MCP setup, when they follow the corresponding README link, then it opens the named setup instructions.
