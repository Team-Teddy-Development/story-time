## Story
As a story-time operator, I want story-time metrics in VictoriaMetrics and Grafana, so that I can measure operation failures and duration.

## Acceptance Criteria
- [ ] Given configured telemetry, when successful and failing operations run, then VictoriaMetrics contains their operation counts, failure counts, and duration histograms, verified on the live stack from a GitHub Actions run that exports through the Xanthos gateway, recorded in the story Evidence
- [ ] Given collected metrics, when the Grafana dashboard is queried by operation and time range, then panels show matching totals, failure rates, and duration distributions, verified on the live stack from a GitHub Actions run that exports through the Xanthos gateway, recorded in the story Evidence
- [ ] Given story identifiers, paths, and credentials, when metrics are emitted, then labels exclude these values and remain within a documented cardinality budget, verified by a native/story-push test that exports to a local OTLP/HTTP receiver
- [ ] Given disabled telemetry or an unavailable backend, when an operation runs, then its result remains correct and export uses bounded buffering and timeouts, verified by a native/story-push test that exports to a local OTLP/HTTP receiver
