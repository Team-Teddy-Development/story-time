## Story
As an operator routing ready stories to local Pi agents, I need manual kickoff and automated dispatch to use the same Story Time reservation before starting work, so that a simultaneous start cannot spend the last slot twice. Scope: same-host native Story Time in linked Git worktrees, the manual story-kickoff path, and the coordinator admission contract. Do not change hosted scheduling, delete work, or enable production dispatch. Test plan: extend the native Rust assignment_contract integration test to race the actual guarded manual kickoff and coordinator claim paths at WIP one and exercise a direct status-only attempt against a full slot. Verify the installed skill path and CLI behavior in disposable worktrees.

## Acceptance Criteria
- [x] Given two eligible stories in linked worktrees with one available Story Time reservation, when manual kickoff and coordinator dispatch start concurrently through their supported paths, then exactly one reserves the slot, the loser receives a typed refusal, and neither kickoff nor dispatch starts work for the loser.
- [x] Given the only slot is reserved, when a supported manual kickoff attempts to start another ready story without a matching reservation, then it does not enter implementation or mutate the other story to in-progress through kickoff.

## Test Plan

Acceptance branch: `feat/ST-169-supervised-acceptance`.
Seams: native admission and story eligibility, the Git common-directory lock and ledger, and the installed kickoff skill. Tracker sync and production dispatch are outside this verification.
