## Story
As a story-time maintainer, I want story machine to run in the native Rust binary, so that state machine checks works without Node and the retained Node CLI shrinks.

## Acceptance Criteria
- [x] Given a fixture backlog and no Node or STORY_TIME_LEGACY_CLI, when the native binary runs story machine with the arguments its Node version accepts, then its stdout, exit code, and file changes match the Node CLI on the same fixture, verified by a native/story-push contract test

## Out of Scope
Changing the command's behavior or output. Converting other commands.

## Notes
Source: ST-036 (Rust conversion plan, epic EP-001, map backlog/EP-001.map.md). Slice: Rest. Constitution Article VIII requires Rust for replacement implementations. Today native/story-push/src/main.rs runs init, push, adopt, and plan natively and passes every other command to skills/story-time/scripts/story.mjs.

## Evidence
- Red 9eb7ac5: all 5 tests in native/story-push/tests/machine_contract.rs failed; native `machine` fell through to the legacy dispatcher (empty stdout, "Commands other than ... require STORY_TIME_LEGACY_CLI").
- Green c1f954b: native/story-push/src/machine.rs ports checkMachine, machineCriteria, machineDiagram, and the CLI handler. native/story-push/src/toml_subset.rs is a pub(crate) port of toml.mjs with the same `line N: reason` errors, and native/story-push/src/models.rs holds the CLI helpers that ST-059 (`story table`) will reuse. config.rs helpers are reused, not copied.
- machine_contract runs Node and native (env cleared, PATH=/nonexistent for native) and compares stdout, stderr, exit code, and the whole sandbox tree: valid machines through check, criteria, and diagram with and without --json; every defect code; 37 TOML inputs including each parser error and unsupported feature; and 15 usage and file cases. The documented example in skills/state-machine/SKILL.md and the ENROLLMENT fixture match Node on all 6 action and flag combinations. 5 passed.
- Checks after rebase on main 80a3ac5: cargo fmt --check clean; clippy -D warnings clean; cargo test --locked 188 passed, 0 failed (37 binaries); npm test 451/451; story-policy.rs 12 passed; story-policy-contract.rs 11 passed.
- Limits: TOML integers at or above 2^53 and lone-surrogate escapes can differ from Node; read errors other than ENOENT, EISDIR, ENOTDIR, and EACCES print Rust's error text. The repository has no real model files, so real-data comparison covers the 2 embedded examples.
