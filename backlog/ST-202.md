## Story
As a team lead writing a PR body, an issue or a report, I want the burndown as a small static SVG, so that I can paste the chart where no dashboard runs.

## Acceptance Criteria
- [ ] Given a sprint of 14 days, when story burndown --sprint ID --svg runs, then the output is one svg element with viewBox 0 0 640 320, one polyline of 14 points for remaining and one for the ideal line, and no script element
