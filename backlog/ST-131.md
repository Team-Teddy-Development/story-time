## Story
As a story author, I want to name a story in another repository of the same registry org in depends_on or relates_to, so that lint checks the link and tools can follow it.

## Acceptance Criteria
- [ ] Given story mcp --root A --root B where B owns VC, when story_lint runs on a VE story with depends_on [VC-109], then no independent.deps error is reported
- [ ] Given the same roots, when a VE story names VC-999 which does not exist, then story_lint reports an independent.deps error
- [ ] Given a third root that also declares VE, when story_lint runs on a story that names a VE ID, then it reports links.ambiguous
- [ ] Given a story body that mentions VC-109 with no frontmatter link, when org-aware story_lint runs, then it reports the warning links.prose_mention
- [ ] Given the VE repository alone, when story lint runs on a story with depends_on [VC-109], then it reports the warning independent.foreign_unresolved and exits 0
- [ ] Given a VE story whose VC dependency is done, when story_update sets status=ready through an org-aware server, then the update succeeds
- [ ] Given a story with relates_to [VC-110], when story set changes another field, then the saved file keeps relates_to directly after depends_on

## Out of Scope
- The hosted registry as an index source. This story builds the index from local `--root`s; ST-130 adds the registry source.
- Neo4j edges (ST-132).
- Automatic rewriting of prose mentions.

## Test Plan
- Affected commands: `story lint`, `story set`, `story mcp --root A --root B` (`story_lint`, `story_update`).
- `cargo test --locked --manifest-path native/story-push/Cargo.toml --test lint_org` covers every lint criterion.
- `cargo test --locked --manifest-path native/story-push/Cargo.toml org_index` covers resolved, missing, and ambiguous IDs.
- `cargo test --locked --manifest-path native/story-push/Cargo.toml --test lint_contract` passes unchanged.
- `npm test` passes with `relates_to` in the Node key order.
- `cargo clippy --manifest-path native/story-push/Cargo.toml --locked --all-targets -- -D warnings` and `cargo fmt --manifest-path native/story-push/Cargo.toml --check` pass.
- The existing contract tests pass unchanged.
