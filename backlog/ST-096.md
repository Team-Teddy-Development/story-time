## Story
As a maintainer, I want the native binary to answer an unknown command, --help, and -h exactly as the Node CLI does, so that story-time runs with no Node at all.

## Acceptance Criteria
- [ ] Given no Node and no STORY_TIME_LEGACY_CLI, when the native binary runs an unknown command, --help, or -h, then its stdout, stderr, and exit code equal the Node CLI output for the same arguments, and main.rs no longer starts the Node CLI, verified by a native/story-push contract test

## Notes
Source: ST-060 (PR #197) report; confirmed on installed cea08eb: Node `story --help` prints `Unknown command "--help".` with usage on stderr and exit 2, native prints the legacy-required message. Every Node command is now native (the legacy-required message lists them all), so the Node fallback in main.rs serves only unknown commands. This story ends EP-001.
