## Story
As a maintainer, I want the Node CLI to treat a command name such as constructor as unknown, so that it fails loudly as the native binary does instead of exiting 0 with no output.

## Acceptance Criteria
- [ ] Given the Node CLI, when it runs story constructor or story toString, then it prints Unknown command with the usage on stderr and exits 2, as the native binary does, verified by a native/story-push test that runs both

## Notes
Source: ST-096 (PR #206) report; confirmed on release 3f1d198: `node story.mjs constructor` exits 0 with no output. `commands[command]` in skills/story-time/scripts/story.mjs finds Object.prototype members; use `Object.hasOwn(commands, command)`.
