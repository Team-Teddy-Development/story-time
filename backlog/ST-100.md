## Story
As a maintainer, I want the Node CLI to treat a command name such as constructor as unknown, so that it fails loudly as the native binary does instead of exiting 0 with no output.

## Acceptance Criteria
- [x] Given the Node CLI, when it runs story constructor or story toString, then it prints Unknown command with the usage on stderr and exits 2, as the native binary does, verified by a native/story-push test that runs both

## Notes
Source: ST-096 (PR #206) report; confirmed on release 3f1d198: `node story.mjs constructor` exits 0 with no output. `commands[command]` in skills/story-time/scripts/story.mjs finds Object.prototype members; use `Object.hasOwn(commands, command)`.

## Evidence
- Red 02342db: `unknown_command_contract.rs` failed with Node exit `Some(0)` against `Some(2)` for `constructor`; `secret_contract.rs` failed because Node printed `The "path" argument must be of type string. Received undefined` and exited 1 where native prints the usage error and exits 2.
- Green 80695ff: `story.mjs` looks up commands with `Object.hasOwn(commands, command)` and secret trackers with `Object.hasOwn(SECRET_SPECS, tracker)`; `src/config/secrets.mjs` `secretSpec` does the same.
- `unknown_command_contract.rs` runs Node and native (env_clear, PATH=/nonexistent) for `constructor`, `toString`, `hasOwnProperty`, `__proto__`, and `valueOf`, compares stdout, stderr, and exit, and requires exit 2. `secret_contract.rs` adds `secret clear constructor`, `secret clear __proto__`, and `secret set toString`, each exit 2 with Node and native matching. `cli.test.mjs` and `secrets.test.mjs` add the Node unit cases.
- Same root cause, also fixed: `story secret clear constructor` crashed Node with a V8 path error and exit 1.
- Limits: other plain-object lookups (parseArgs flags, toml `__proto__` keys, gateway status maps) were checked and show no user-visible difference in the CLI; not changed.
- Checks on main 51efc76: `cargo fmt --check` ok; clippy `-D warnings` ok; `cargo test --locked` 322 passed, 0 failed; `npm test` 467/467; `scripts/story-policy.rs` 12 passed; `test/story-policy-contract.rs` 11 passed.
