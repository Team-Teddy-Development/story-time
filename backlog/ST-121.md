## Story
As a project owner whose agents write through MCP, I want story_update to refuse done unless the story carries acceptance evidence, so that only an accepted story reaches done.

## Acceptance Criteria
- [ ] Given a story with an unticked acceptance criterion or no non-empty Evidence section, when story_update sets status=done, then the result is lifecycle_refused with a finding naming what is missing and the file is unchanged, verified by a native/story-push protocol test
- [ ] Given a story whose acceptance criteria are all ticked and whose Evidence section is not empty, when story_update sets status=done, then the story is done and the result carries the audit evidence, verified by a native/story-push protocol test
