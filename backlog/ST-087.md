## Story
As a maintainer, I want the Node CLI to fail on a command it does not run, so that scripts and agents see the failure instead of exit 0.

## Acceptance Criteria
- [x] Given the Node CLI, when it runs metrics or an unknown command, then it exits non-zero and says which binary runs metrics, verified by a native/story-push test that runs the Node CLI

## Notes
Source: ST-068 trial runs. `node skills/story-time/scripts/story.mjs metrics` prints `Unknown command "metrics".` and exits 0, while help lists metrics. Verify with a Rust test that runs the Node CLI (Constitution Article VIII).

## Evidence
- Premise correction: the Node CLI already exited 2 for an unknown command (since fe1dc0a). The defect was only the message for native-only commands.
- Red d3fb675 `test(ST-087): Node CLI names the native binary for native-only commands (red)`: `native/story-push/tests/node_unknown_command.rs` failed because Node printed `Unknown command "metrics".` where the native-binary line was expected.
- Green cd888ca `fix(ST-087): ...`: `skills/story-time/scripts/story.mjs` adds `NATIVE_ONLY = {plan, adopt, issues, metrics}`. Each prints `The "<cmd>" command runs only in the native story binary (native/story-push); this Node CLI cannot run it.`, then usage, and exits 2. Other unknown commands keep `Unknown command "<cmd>".` with exit 2.
- Checks on main b97f5ef: `cargo fmt --check` ok; clippy `-D warnings` ok; `cargo test --locked` 55 binaries, 301 passed, 0 failed; `npm test` 461/461; `scripts/story-policy.rs` 12 passed; `test/story-policy-contract.rs` 11 passed.
- Drift guard 8e03535: `the_node_cli_never_calls_a_native_command_unknown` runs Node for every entry in `NATIVE_COMMANDS` and fails if Node prints `Unknown command`. Removing `metrics` from NATIVE_ONLY made it fail with `native command metrics needs a Node handler or a NATIVE_ONLY entry`.
