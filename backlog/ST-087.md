## Story
As a maintainer, I want the Node CLI to fail on a command it does not run, so that scripts and agents see the failure instead of exit 0.

## Acceptance Criteria
- [ ] Given the Node CLI, when it runs metrics or an unknown command, then it exits non-zero and says which binary runs metrics, verified by a native/story-push test that runs the Node CLI

## Notes
Source: ST-068 trial runs. `node skills/story-time/scripts/story.mjs metrics` prints `Unknown command "metrics".` and exits 0, while help lists metrics. Verify with a Rust test that runs the Node CLI (Constitution Article VIII).
