## Story
As a maintainer removing story-time from a machine, I want the Rust installer to uninstall the skills and reject bad flags, so that every installer path needs no Node.

## Acceptance Criteria
- [x] Given installed story-time skills next to other skills, when the Rust installer runs with --uninstall, and when it runs with an unknown flag, a missing value, an unknown agent, an unknown scope, or --help, then its output, removed files, and exit codes match node scripts/install.mjs, verified by a native/story-push contract test

## Evidence
- Red bbf8dd3 (was 44a2cdc before the rebase): 5 of 14 contract tests failed. Uninstall and help failed with `stdout differs for ["--agent", "all", "--uninstall"]` and `stdout differs for ["--help"]`, because both flags were still rejected as unknown. `usage_errors_match_node` failed with `stderr differs for []`, because the usage text had no `--uninstall`.
- Green d212beb (was 91ad1d0 before the rebase): `story_install_skills.rs` adds `--uninstall`, which removes only the plan targets that exist. With `--dry-run` it prints `would remove <path>`; otherwise it prints `Removed story-time skills for <agents>.`, even when nothing was installed. It also adds `--help`, which runs after parsing, so a parse error still wins. An empty `--agent` now counts as missing, as in Node.
- `install_skills_contract.rs` has 5 new tests. They run Node and Rust (env_clear, PATH=/nonexistent, HOME=temp) and compare stdout, stderr, exit code, and the tree with modes:
  - uninstall next to other skills (`my-own` survives) under the claude and codex user, project, and `--codex-home` roots;
  - uninstall with `--dry-run`;
  - uninstall with nothing installed;
  - `--help`;
  - 19 usage-error argument lists: no arguments, a missing or empty `--agent`, positional and extra arguments, `--bogus`, `--`, `--agent=all`, a missing value for each valued flag, `--help --agent`, unknown or empty agent and scope, and their combinations with `--uninstall`.
- The usage text differs from Node in two named ways, and the test converts both back explicitly (`as_node_usage`). The program is named `story-install-skills` instead of `node scripts/install.mjs`. The Rust-only `--source DIR` line stays, because the binary needs it whenever it does not run from its build checkout.
- Limits: in Node, `--agent constructor` and `--scope toString` read inherited object keys, which gives the wrong error or plans writes into `[object Undefined]/`. Rust rejects them correctly. That is a Node defect; the Node installer is to be retired after ST-108.
- Checks on main 0f94b3e: `cargo fmt --check` ok; clippy `-D warnings` ok; `cargo test --locked` 341 passed, 0 failed (`install_skills_contract` 14); `npm test` 467/467; `scripts/story-policy.rs` 12 passed; `test/story-policy-contract.rs` 11 passed.
