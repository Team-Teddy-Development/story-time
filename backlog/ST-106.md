## Story
As a maintainer setting up a machine or a repository, I want a Rust installer that copies the skills, so that installing story-time needs no Node, as Constitution Article VIII requires.

## Acceptance Criteria
- [ ] Given a temporary HOME and a project directory, when the Rust installer runs with --agent codex, claude and all, with --scope user and --scope project --project DIR, with --codex-home DIR, and with --dry-run, then it prints the same output, writes the same files without the skills' test folders, and exits with the same code as node scripts/install.mjs, verified by a native/story-push contract test
- [ ] Given skills already installed, when the Rust installer runs without --force and then with --force, then it refuses and writes nothing, then replaces them, matching node scripts/install.mjs output and exit codes, verified by a native/story-push contract test
