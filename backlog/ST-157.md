## Story
As a maintainer of a Gitea repository (cartographer-core, xanthos), I want story sync-merge and story check-pr to work with the Gitea tracker, so that merges close and comment on story issues there as they do on GitHub

## Acceptance Criteria
- [ ] Given a repository whose settings name tracker gitea, when story sync-merge runs after a push to the default branch in Gitea Actions, then each merged PR's named issues get one merge comment and match their cards
- [ ] Given a Gitea pull request body, when story check-pr runs in Gitea Actions, then it applies rules 1 to 4 with the same messages and exit codes as on GitHub

## Notes
- Source: the owner asked on 2026-11-16 to install story-sync in cartographer and xanthos. Both use `tracker: gitea` (cartographer/cartographer-core, team-teddy/xanthos), and `story sync-merge` (ST-151) reports `skipped (unsupported tracker)` there. `story check-pr` (ST-152) calls `gh`. Not installed in those repositories until this story is done.
- The gateway already has Gitea issue writes; the new parts are Gitea's merged-PR-for-commit lookup, the comment list with the bot user, the last-successful-run anchor in Gitea Actions, and the `.gitea/workflows` templates.
