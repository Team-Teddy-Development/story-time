## Story
As a team lead in a repository with no sprint history yet, I want the forecast to sample the points we finish each day, so that I get 50% and 85% dates from the first week of tracking instead of unknown.

## Acceptance Criteria
- [ ] Given two closed sprints and 2 points done on each day from 2026-10-19 to 2026-11-15, and stories A and B of size 5 each not done, when story forecast --ids A,B --today 2026-11-15 --json runs, then sample_source is daily_throughput and both rows have the date 2026-11-20
- [ ] Given no closed sprint and no done event between 2026-10-19 and 2026-11-15, when story forecast --ids A --today 2026-11-15 --json runs, then it exits 0 and both rows have the date unknown with the reason no done points in the 28 days to 2026-11-15
