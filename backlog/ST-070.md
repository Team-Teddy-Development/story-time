## Story
As a story-time maintainer, I want npm test to delete the temp directories it creates, so that repeated test runs do not fill the disk.

## Acceptance Criteria
- [x] Given a machine with no story-push-, story-judge-, story-cfg-, story-install-, or story-fakebin- directories in the temp dir, when npm test runs once and passes, then none of those directories remain, verified by a Rust test that runs npm test with TMPDIR set to an empty directory and checks it is empty afterwards

## Out of Scope
Deleting directories that other sessions or CI runners own. Rust test temp handling, which already removes its fixtures.

## Notes
Source: found while verifying ST-069 on 2026-11-14. One `npm test` run added 16 /tmp/story-push-* directories (672 before, 688 after). Counts in /tmp: story-push 688, story-fakebin 688, story-cfg 473, story-install 344, story-judge 258. Creators: skills/story-time/scripts/test/cli-push.test.mjs:31, fake-trackers.mjs:124, cli-config.test.mjs:13, cli-judge.test.mjs:32, test/install.test.mjs:15; each calls mkdtemp with no matching removal. Spark ran out of disk on 2026-11-13 from abandoned temp build dirs, so leaks matter here.

## Test Plan
Red: run npm test with TMPDIR pointed at an empty directory from a Rust test; it is not empty afterwards. Green: each test removes its directories (for example with t.after or a shared tracked-temp helper).

## Evidence
- Red a57437b: `npm_temp_cleanup` (native/story-push/tests/npm_temp_cleanup.rs) runs the root `npm test` with TMPDIR, TEMP, and TMP set to a new empty directory. It failed with "npm test left 99 entries in TMPDIR" across 11 prefixes: story-push 16, story-fakebin 16, story-design 12, story-cfg 11, story-cli 11, story-time 10, story-install 8, story-judge 6, story-secret 6, story-ids 2, story-nogit 1. The leak was wider than the five creators named in Notes.
- Green 642dbae: one helper, skills/story-time/scripts/test/temp-dir.mjs `makeTempDir(prefix)`, records each directory and removes them all on process exit. All ten files that called mkdtemp use it. No test was skipped or weakened. The guard sets NODE_DISABLE_COMPILE_CACHE=1 because npm 11 itself creates a reused `node-compile-cache` directory; that is the only exemption. Guard passes.
- Real path: /tmp story-* count was 4612 before and 4612 after one `npm test` run.
- Checks after rebase on main 781f9f6: cargo fmt --check clean; clippy -D warnings clean; cargo test --locked 128 passed, 0 failed (27 binaries); npm test 431/431; story-policy.rs 12 passed; story-policy-contract.rs 11 passed.
- Limits: a test process killed by a signal still leaves its directories. Existing leftovers in /tmp were not deleted, because some may belong to other sessions.
