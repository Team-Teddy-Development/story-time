## Story
As a story refiner, I want lint to warn rather than error when depends_on names a story that exists only on an open proposal branch, so that dependent stories can be refined before the proposal merges.

Evidence (2026-11-26): ST-195's `depends_on: [ST-194]` failed lint with "Depends on ST-194, which does not exist" (native/story-push/src/lint.rs ~435-461) while ST-194 sat on its `story-time/ST-194` branch. next_id and org_index already see open proposals. A truly unknown id must stay an error.

## Acceptance Criteria
- [ ] Given depends_on names an id that exists only on a `story-time/<id>` ref or in the story server registry, when lint runs, then it reports a warning; and given an id known nowhere, then it still reports an error.
