## Story
As a story-time maintainer, I want story secret to run in the native Rust binary, so that storing tracker tokens works without Node and the retained Node CLI shrinks.

## Acceptance Criteria
- [x] Given a fixture backlog and no Node or STORY_TIME_LEGACY_CLI, when the native binary runs story secret with the arguments its Node version accepts, then its stdout, exit code, and file changes match the Node CLI on the same fixture, verified by a native/story-push contract test

## Out of Scope
Changing the command's behavior or output. Converting other commands.

## Notes
Source: ST-036 (Rust conversion plan, epic EP-001, map backlog/EP-001.map.md). Slice: Rest. Constitution Article VIII requires Rust for replacement implementations. Today native/story-push/src/main.rs runs init, push, adopt, and plan natively and passes every other command to skills/story-time/scripts/story.mjs.

## Evidence
- Red dcd7b89 (rebased): all 6 tests in native/story-push/tests/secret_contract.rs failed; native `secret` fell through to the legacy dispatcher (empty stdout, "Commands other than ... require STORY_TIME_LEGACY_CLI").
- Green 39c936f plus 1627855: native/story-push/src/secret.rs runs `story secret set|status|clear <github|ado|gitea|jev>` natively. It writes `.story-time/.<name>.env` through a 0600 temp file and a rename, adds `*.env` to .gitignore as Node does, reads the token from the first stdin line or a hidden terminal prompt, and masks it in status like Node. 1627855 switches its trim and line-terminator helpers to the shared lenient_story parser after the ST-048 merge.
- secret_contract runs Node, rebuilds the same fixture, then runs native with env cleared and PATH=/nonexistent, and compares stdout, stderr, exit code, and the whole tree (path, mode, bytes). Cases: set for each provider, replace a 0644 file, .gitignore present (LF, CRLF), extended, and `*.envx`; status absent, present, short, 0644 unusable, missing key, environment, and git-tracked; clear present and absent; and failures (no args, bad action, unknown provider, inline value, empty stdin, whitespace token, missing --config value, invalid settings). Every run asserts the fake values never appear in stdout or stderr. 6 passed.
- Checks after rebase on main 16004cc: cargo fmt --check clean; clippy -D warnings clean; cargo test --locked 186 passed, 0 failed (36 binaries); npm test 451/451; story-policy.rs 12 passed; story-policy-contract.rs 11 passed.
- Limits: the hidden terminal prompt is not tested (no TTY in tests). Operating-system errors other than a missing file print Rust's error text, not Node's. No real token file was read.
