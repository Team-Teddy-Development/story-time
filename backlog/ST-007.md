## Story
As a coding agent operator, I want to read and update stories through MCP tools, so that agents can use the story lifecycle without constructing shell commands.

## Acceptance Criteria
- [ ] Given an MCP client and an authorized repository, when it lists and reads stories, then typed results match the repository configuration and backlog.
- [ ] Given a valid story change, when the client calls an approved write tool, then the change follows lifecycle rules and returns its persisted identity and audit evidence.
- [ ] Given invalid input, an unauthorized path, or a concurrent conflicting write, when a tool is called, then it returns a typed failure without unintended changes or secret disclosure.
