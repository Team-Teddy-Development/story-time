## Story
As a story-time maintainer, I want story help to run in the native Rust binary, so that the help text works without Node and the retained Node CLI shrinks.

## Acceptance Criteria
- [x] Given a fixture backlog and no Node or STORY_TIME_LEGACY_CLI, when the native binary runs story help with the arguments its Node version accepts, then its stdout, exit code, and file changes match the Node CLI on the same fixture, verified by a native/story-push contract test

## Out of Scope
Changing the command's behavior or output. Converting other commands.

## Notes
Source: ST-036 (Rust conversion plan, epic EP-001, map backlog/EP-001.map.md). Slice: Finish. Constitution Article VIII requires Rust for replacement implementations. Today native/story-push/src/main.rs runs init, push, adopt, and plan natively and passes every other command to skills/story-time/scripts/story.mjs. When this is the last command converted, native main.rs stops dispatching to the Node CLI.

## Evidence
- Red 4942c8a: `help_contract` failed with `stdout differs for [] []` (native printed nothing) and `exit code differs for ["help", "--dir"]` (native exit 1 with the legacy-required message; Node exit 2 `Flag --dir needs a value.`).
- Green 0298e04: `src/help.rs` embeds `skills/story-time/scripts/usage.txt` with `include_str!`, parses flags and loads the config as Node's main() does, and prints the usage; main.rs treats no arguments as `help`. story.mjs reads the same usage.txt, so the text has one copy and cannot drift. `help` is in the dispatch table and the five doc lists; the SKILL.md row says Native Rust.
- The contract test compares Node and native (env_clear, PATH=/nonexistent) on stdout, stderr, exit code, and a tree snapshot for no arguments, `help`, `--json`, extra arguments, `--dir`, a missing `--config`, STORY_TIME_DIR, missing flag values (exit 2), and invalid configs (exit 1).
- Real repository: 4 invocations compared with Node, 0 differing.
- Limit: `story --help` and `-h` are unknown commands in Node (exit 2, usage on stderr); native still routes unknown commands to the legacy fallback.
- Checks: `cargo fmt --check` ok; `cargo clippy --locked --all-targets -- -D warnings` ok; `cargo test --locked` 317 passed, 0 failed; `npm test` 461/461; `scripts/story-policy.rs` 12 passed; `test/story-policy-contract.rs` 11 passed.
