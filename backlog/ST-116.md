## Story
As an agent operator running story mcp --write next to CLI commands, I want CLI writes to take the same repository lock, so that a CLI write never silently replaces an MCP write.

## Acceptance Criteria
- [x] Given another process holding the repository write lock, when story set, story note, story new or story split runs, then it exits non-zero with a lock-held message and changes no file, and once the lock is free it succeeds, verified by a native/story-push test that holds the lock while each command runs

## Notes
Source: ST-112 (PR #254) Jev review (cli_race, 0.76) and ST-006 spike open question 4. MCP story_update and story_note take adoption_apply::lock_repository and check a sha256; CLI set, note, new and split take no lock, so a CLI write between an MCP hash check and its rename is lost.

## Evidence
- Criterion 1: `native/story-push/tests/cli_lock.rs`.
  - `cli_writes_wait_for_the_repository_lock` holds the root lock (`File::open(root).try_lock()`) while `set`, `note`, `new` and `split` each run. Each one exits 1 with empty stdout and the message "Another process held the repository write lock on <root> for 3 seconds. Wait for it to finish, then rerun the command." The byte-and-mode snapshot is unchanged. Once the lock is dropped, each command exits 0 and writes.
  - `a_cli_write_waits_for_a_writer_that_finishes` releases the lock after 300 ms, and each command then succeeds.
- Red (1c1ee91): `set` exited 0 and wrote while the lock was held.
- Green (bca36ee, 9541fcb): `adoption_apply::lock_for_write` locks the config root, the same folder `story mcp --root` locks. It retries `try_lock` for up to 3 seconds and then refuses. The lock is taken in `set`, `note`, `split`, and in `new_story::run` outside `create`.
- The bounded wait keeps parallel `story new` working. `create_race.rs` again requires every racing create to succeed, and it passed 5 of 5 runs.
- Checks on the rebased branch: fmt ok; clippy clean; cargo 72 binaries, 365 passed, 0 failed; npm pass 457 fail 0; story-policy 12 passed; contract 11 passed.
- Real data: uncontended `set` and `note` over every story of a scratch copy of this backlog, Node against native (PATH=/nonexistent): 240 compared, 0 differing.
