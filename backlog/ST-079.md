## Story
As a maintainer, I want native story show to treat an empty id the way Node does, so that scripts see the same error and exit code.

## Acceptance Criteria
- [x] Given no Node, when the native binary runs story show with an empty id, then it prints A story id is required. and exits 2 like the Node CLI, verified by a case in native/story-push/tests/show_contract.rs
