## Story
As a maintainer, I want story init --config settings.json to work in Node as it does natively, so that both runtimes accept the same settings paths.

## Acceptance Criteria
- [ ] Given an empty directory, when Node and native story init --config settings.json run on the same fixture, then both exit 0 and write the same files, verified by a native/story-push contract test

## Notes
Source: ST-095 (PR #205) report; confirmed on release 3f1d198: Node `story init --config settings.json` exits 1 with `ENOENT ... .story-time/.gitignore` (ensureGitignore writes into `<root>/.story-time` without creating it), while native creates the directory and succeeds (pinned by `explicit_path_beats_environment_and_custom_roots_are_relative_to_cwd`).
