## Story
As a story-time maintainer, I want retained push process tests to report complete deterministic results, so that regression gates expose real failures without losing the child process cause.

## Acceptance Criteria
- [ ] Given the real retained push test processes and captured failure evidence, when the second-push test runs repeatedly, then its output is complete JSON and a failing child reports its exit status and stderr without weakening assertions.

## Source task
ST-018 verification, source implementation commit `386e85655c9fd73e7acc904b0b182fb49caaff61`. Retained executable/test bytes were unchanged relative to its base. This is separate follow-up work, not ST-018 implementation scope.

## Evidence
`ST018-final-source-gates` passed native G1-G3 but Node G4 exited 1. Its gate runner retained only a shortened failing-output summary. A standalone `npm test` then passed 418/418. The captured complete G4 chain subsequently failed 417/418: `skills/story-time/scripts/test/cli-push.test.mjs:70`, "a second push updates the same issue", `SyntaxError: Unexpected end of JSON input` at line 75. The test parses stdout before asserting the child exit status and does not show the child stderr. Its mechanism remains undiagnosed; do not call a later passing run a fix.

`strace -f -e trace=process,write -s 512 -o /tmp/ST018-legacy-push.trace node --test skills/story-time/scripts/test/cli-push.test.mjs` passed 16/16. A traced full Node run passed 418/418. Logs: `/tmp/ST018-g4-full.log`, `/tmp/ST018-g4-diagnosis.log`, `/tmp/ST018-legacy-push.log`, `/tmp/ST018-g4-traced.log`. Retain copies under the ST018-planning-skills durable evidence directory before cleanup. No production tracker was contacted by these fake-tracker fixtures.

## To plan
Capture child code/stdout/stderr at the actual failing boundary. Reproduce the mechanism, add a Rust-controlled regression, and fix the cause without skipping tests, masking empty stdout, or converting the failure to success. New or replacement executable implementations and tests must be Rust. Preserve the retained failure history.
