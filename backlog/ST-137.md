## Story
As a hosted story MCP client, I want the graph, write, and comment tools checked on the deployed server, so that I know they work against real GitHub repositories and the Neo4j sidecar.

## Acceptance Criteria
- [ ] Given the deployed server with the Neo4j sidecar, when story_graph runs for VC-109 with direction dependents, then it returns the linked VE stories and the synced SHAs
- [ ] Given the Neo4j container is stopped, when story_graph and /readyz are called, then story_graph returns graph_unavailable and /readyz returns 200
- [ ] Given the sandbox repository, when story_update runs, then it returns a PR URL, and the PR shows the bot author and the Requested-by trailer
- [ ] Given the same write repeated with the old expected_sha256, when story_update runs, then it returns conflict
- [ ] Given a comment on a sandbox issue, when story_resolve_comment runs, then one bot reply is posted and story_comments shows the comment as resolved

## Out of Scope
- Server code. ST-132, ST-133, and ST-134 deliver it.

## Test Plan
- Affected: the deployed server at `https://storytime.teamteddy.net` and the sandbox repository `Varsity-Engine/story-time-sandbox`. No `story` command changes.
