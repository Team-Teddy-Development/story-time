## Story
As a story-time maintainer, I want native Rust Gitea synchronization, so that local stories can be mirrored without running the Node tracker path.

## Acceptance Criteria
- [x] Given Gitea settings and Story Time Markdown, when the Rust CLI pushes an active story, then it creates an issue and saves its validated local issue link.
- [x] Given a linked story, when pushed again, then the existing issue updates without creating a second issue.
- [x] Given changed managed labels, when pushed, then stale managed labels are removed and team-owned labels remain.
- [x] Given terminal and active story states, when pushed, then the remote issue closes and reopens as appropriate.
- [x] Given malformed inputs or API failures, when commands run, then they return sanitized failures and preserve truthful progress.
- [x] Given a real isolated Gitea instance, when the committed Rust live verifier runs, then it asserts these observable issue and local-file states.
- [x] Given PR #16, when required CI and owner-team review pass, then the native path is integrated without bypassing repository protections.

## Test Plan
Run `cargo test --offline --manifest-path gitea-gateway/Cargo.toml`, format checks, and Clippy with warnings denied. Invoke the compiled CLI through the Rust HTTP integration tests. Run the committed live verification example against an isolated Gitea process. Run the existing Node and Rust repository-policy regression tests. Check GitHub CI and owner-review status before integration.

## Evidence
The parent observed 26 Rust tests pass, zero failures. Existing npm regression tests passed 408 tests. The isolated live Gitea verifier returned `LIVE_GITEA_VERIFIED` with exit zero. See `docs/gitea-live-verification.md` for commands and assertions. Rust and regression CI passed before this tracking-only change. Owner-team review remains required.

## Out of Scope
Production Gitea compatibility certification, full repository Rust conversion, automatic ambiguous-create reconciliation, and concurrent label-editor locking.
