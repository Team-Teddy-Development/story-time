## Story
As a Story Time maintainer, I want repeatable work item templates, so that each item records what a reviewer needs to act on it.

Use the provider spikes to choose template ownership and mappings. Treat task and feature as candidate labels, not new Story Time types. Out of scope: adding a new tracker integration.

## Acceptance Criteria
- [ ] Given the provider findings, when a maintainer creates a work item through a supported path, then the chosen template supplies the required sections for that item type without inventing unsupported provider fields.
