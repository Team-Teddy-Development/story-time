## Story
As a maintainer, I want every workflow to use action versions that run on Node.js 24, so that CI does not warn and does not break when GitHub removes Node.js 20

## Acceptance Criteria
- [ ] Given every file in .github/workflows, when a workflow runs on GitHub Actions, then its log has no 'Node.js 20 is deprecated' warning
